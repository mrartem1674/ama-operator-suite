# The AMA Operator Suite

**The AMA Operator Suite** is a production-grade collection of lightweight, client-side web utilities designed for digital entrepreneurs, freelancers, and micro-agency owners. Built with modern HTML, Tailwind CSS, and vanilla JavaScript, these standalone tools require no backend databases or complex environments—just open them directly in any browser and start optimizing your workflow.

---

## 🛠️ Included Tools & Applications

1. **Service Selection & Scorecard Calculator** (`ama-scorecard-pro.html`)
   * Evaluates multiple service ideas across key criteria (Skill Viability, Setup Friction, Monetization Speed, and Scalability).
   * Features dynamic column management, customizable formula weighting matrices, and local browser persistence.

2. **30-Day Launch Plan & Habit Tracker** (`ama-launch-tracker.html`)
   * Provides a structured 4-week execution roadmap from foundational niche validation to client onboarding and scaling.
   * Includes interactive task checkmarks, dynamic momentum progress bars, and clean executive reporting layouts.

3. **Scope of Work (SOW) & Boundary Generator** (`ama-sow-generator.html`)
   * Compiles watertight client agreements, boundary enforcers, and change-order protections in real time.
   * Features one-click clipboard copying and clean print-to-PDF formatting to eliminate scope creep.

4. **Margin & Pricing Calculator** (`ama-pricing-calculator.html`)
   * Cures pricing panic by comparing hourly billing ceilings against high-margin fixed-package pricing models.
   * Factors in software overhead, billable hours, and target net income goals to compute minimum viable rates and profit buffers.

---

## 🚀 Quick Start Guide

1. Clone or download this repository to your local machine.
2. Open any `.html` file (e.g., `ama-scorecard-pro.html`) directly in Google Chrome, Safari, Firefox, or Edge.
3. Your data automatically saves to your browser's `localStorage` as you input parameters.
4. Use the **Export Report** or **Print** buttons to instantly generate clean client-ready documentation or physical records without website chrome.
